# Agent Instructions

Before making changes, read:

- docs/agents/current-agent-plan.md
- docs/agents/agent-progress-log.md
- docs/agents/decisions.md
- docs/agents/todo.md

Keep these files updated as work progresses so the project can recover if Antigravity loses agent state.

## Required Workflow

1. Read the current handoff docs.
2. Summarize the active goal.
3. Make minimal, focused changes.
4. Update the handoff docs with:
   - what changed
   - files touched
   - decisions made
   - validation performed
   - remaining work
5. Commit meaningful progress when appropriate.
